# מודול התנהלות כלכלית — מסמך עיצוב (UI/UX)

> נלווה ל-`finance-module-spec.md` (המודל והלוגיקה). מסמך זה עוסק ב**איך זה נראה ומרגיש** —
> פריסה, אנטומיית קומפוננטות, מצבים, צבעים, RTL ורספונסיביות. לאישור סופי לפני בנייה.
> מקור האמת ללוגיקה הוא ה-spec; מקור האמת לטוקנים הוא שפת העיצוב הקיימת (`tailwind.config.ts`).

**סטטוס:** טיוטה לאישור. טרם נבנה קוד.

---

## 1. עקרונות עיצוב

- **המשכיות עם האפליקציה** — אותם טוקנים, אותו `ScreenScaffold`, אותו `card`, אותו `field`. המודול מרגיש חלק מ-Multitask, לא אי נפרד.
- **המספר הוא הגיבור** — בכל כרטיסיית תקציב, ה"כמה נשאר" הוא האלמנט הכי גדול וברור. הכל סביבו משני.
- **צבע = סטטוס, לא קישוט** — 🔴/🟢 רק לסיגנל חלוקה; הענבר/מותג לפעולות. אין צבעוניות מיותרת.
- **RTL מלא** — `ps-`/`pe-`, מספרים וטווחי תאריכים ב-`dir="ltr"` בתוך עטיפה (כמו טווח תאריכים בתוכניות).
- **מובייל-first** — הכרטיסיות נערמות לטור אחד במובייל; הרשת המרובה היא שדרוג דסקטופ.

### טוקנים בשימוש
| שימוש | טוקן |
|---|---|
| טקסט ראשי / משני / מטא | `text-ink-900` / `text-ink-500` / `text-ink-400` |
| גבולות / רקעים עדינים | `border-ink-300` / `bg-ink-100` |
| פעולה ראשית / מותג | `primary-500` (ענבר) / `brand-gradient` |
| 🟢 חיובי (חלוקה גבוהה, עודף) | `success` (#10b981) |
| 🔴 שלילי (חלוקה נמוכה, גרעון, חריגה) | `danger` (#ef4444) |
| כרטיס / רדיוס / צל | `.card` / `rounded` (10px) / `shadow-DEFAULT` |
| קלט / select | `.field` |

## 2. ניווט המודול

פריט סיידבר חדש: **"התנהלות כלכלית"** (אייקון `Wallet` / `PiggyBank` מ-lucide).
מובל ל-shell עם טאבים מנותבים (כמו `ProjectShell`):

```
התנהלות כלכלית
├── סקירה        /app/finance
├── תקציבים      /app/finance/budgets
├── חשבונות      /app/finance/accounts
├── היסטוריה     /app/finance/history
└── שבלונות      /app/finance/templates
```

ה-shell: כותרת `ScreenScaffold` + שורת טאבים אופקית (RTL, גלילה במובייל) + `<Outlet>`.

## 3. מסך סקירה (`/app/finance`)

תצוגת-על במבט אחד. מלמעלה למטה:

1. **שורת סטטיסטיקה** — 3–4 כרטיסי סיכום קטנים (KPI): סך הוקצב החודש · סך חויב · סך נשאר · יתרת חשבונות כוללת. כל אחד: מספר גדול + תווית + חץ מגמה.
2. **תחזית — "מה יוצא ומתי"** — ציר זמן/רשימה של ירידות חשבון עתידיות מתוכננות, מקובצות לפי תאריך, עם סכום מצטבר. חיובים שעוד לא ירדו מסומנים שונה מ-future-dated withdrawals (גוון מקווקו).
3. **רצועת חשבונות** — שורת צ'יפים, צ'יפ לכל חשבון עם יתרה נוכחית וצבע סוג.
4. **תקציבים בקצרה** — גריד מצומצם של מיני-כרטיסיות (קישור לטאב תקציבים).

## 4. מסך תקציבים (`/app/finance/budgets`)

### 4.1 פריסה
```
┌─ שורת בקרה ───────────────────────────────────────────┐
│ [סינון: קטגוריה ▾] [שיתוף ▾] [סטטוס ▾]   [תצוגה: ☐☐☐] │  ← ViewModeToggle
└──────────────────────────────────────────────────────┘
┌──────────┐ ┌──────────┐ ┌──────────┐
│ כרטיס    │ │ כרטיס    │ │ כרטיס    │   ← רשת: single / columns / rows
│ תקציב    │ │ תקציב    │ │ תקציב    │      בחירת אילו תקציבים מוצגים
└──────────┘ └──────────┘ └──────────┘
```
- **בורר תקציבים מוצגים** — multi-select (צ'יפים) לבחור אילו כרטיסיות רואים במקביל.
- **סינון** — לפי קטגוריה / שיתוף (אישי/משפחתי) / סטטוס (תקין/חריגה).
- **`ViewModeToggle`** — single (אחד גדול) / columns (זה לצד זה) / rows (ערום). נשמר ב-`localStorage` (`multitask:finance:viewMode`).

### 4.2 אנטומיית כרטיסיית תקציב
```
┌─────────────────────────────────────────┐
│ ● אוכל                    [חודשי] [⋯]    │  כותרת: נקודת-צבע+שם, צ'יפ תקופה, תפריט
│                                          │
│            ₪ 5,500                        │  ← הגיבור: שארית התקופה (גדול)
│            נשאר החודש                     │
│ ▓▓▓▓▓▓▓▓░░░  8% נוצל                      │  פס התקדמות עדין
│                                          │
│ 🔴 189 ₪/יום   ·  🟢 1,320 ₪/שבוע        │  ← חלוקות: צבע מול בסיס
│                                          │
│ + הוסף הוצאה            (מהירה / שבלונה)  │  הוספה מהירה
│ ─────────────────────────────────────── │
│ ✔ שיעור גיטרה   200   שני   [💳 עתידי]   │  שורות הוצאה
│ ☐ סופר          ―     ―     [⚡ מיידי]    │
└─────────────────────────────────────────┘
```
- **חלוקות** מוצגות לפי העדפת התצוגה של התקציב (חודש/שבוע/יום, אפשר כמה). כל אחת צבועה 🔴/🟢 לפי השוואה לבסיס.
- **תפריט `⋯`**: עריכה (מצב גרסה) · היסטוריה · סגירה חודשית · ארכוב.

### 4.3 שורת הוצאה (ExpenseRow) — שני המצבים
לכל מופע שני אינדיקטורים נפרדים:
- **וי חיוב לתקציב** — צ'קבוקס שמאלי. מצב `auto` → מסומן אוטומטית בתאריך (read-only/מוצג כסומן); מצב `manual_check` → לחיצה מורידה מהתקציב.
- **תג ירידה מהחשבון** — `⚡ מיידי` / `💳 עתידי (תאריך)` + וי "שולם בפועל" כשירד.
- שדות: שם · סכום · תאריך/יום · חשבון (אייקון סוג).
- **מצבי שורה:** רגיל · חויב-לא-ירד (גוון תכלת) · ירד-בפועל (מלא) · מופע ידני שעבר זמנו (פיגור, גוון אדום עדין).

### 4.4 מצב עריכת תקציב (גרסה)
מודאל/פאנל ש**מכריח כותרת לגרסה** לפני שמירה:
- שדה כותרת (חובה) · סכום · תקופה (חודשי/שנתי) · צבע/אייקון · העדפות תצוגת שארית.
- בתחתית: "גרסאות קודמות" — רשימת היסטוריה (כותרת, סכום, טווח תוקף, מי שינה).

### 4.5 סגירה חודשית / עודף-גרעון
פאנל per-תקציב:
- כותרת חודש · הוקצב · חויב · **יתרה** (🟢 עודף / 🔴 גרעון, מספר גדול).
- **"למה"**: רשימה אוטומטית (הוצאות חורגות/חוסכות מול בסיס) + שדה הערה ידנית.
- **כפתור העברה**: בחירת סכום (ברירת מחדל = כל היתרה, ניתן לשנות) + תקציב יעד → העברה חד-פעמית. רישום בהיסטוריה.

## 5. מסך חשבונות (`/app/finance/accounts`)

- **כרטיסי חשבון** — שם, סוג (אייקון: `Landmark` בנק / `CreditCard` אשראי / `Banknote` מזומן), **יתרה נוכחית** גדולה.
- **פעולה: העברה בין חשבונות** — דיאלוג: מקור → יעד, סכום, תאריך, הערה. יוצר זוג תנועות מקושר.
- **טבלת תנועות** (`configurable-table`) — תאריך, תיאור, סכום (חתום, צבוע), חשבון-נגד (להעברות), קישור להוצאה.
- **היסטוריית חשבון** — מי שינה / מתי / מה (audit).

---

## 6. מסך היסטוריה/ניתוח (`/app/finance/history`)

- **בורר טווח תאריכים** (`dir="ltr"`).
- **per-תקציב לאורך זמן** — טבלה/גרף עמודות של עודף/גרעון חודשי. צבע 🟢/🔴 לפי סימן.
- לחיצה על חודש → פירוט הסגירה של אותו חודש (אותו פאנל מ-§4.5, קריאה בלבד).
- **לוג audit מאוחד** מסונן — תקציבים + חשבונות, עם סינון לפי ישות/משתמש/תאריך.

---

## 7. מסך שבלונות (`/app/finance/templates`)

- **רשימת שבלונות** — כרטיס לכל שבלונה: שם + תקציב/חשבון/אמצעי תשלום ברירת-מחדל.
- **עורך שבלונה** — כל שדות ברירת המחדל; הוספה / עריכה / מחיקה (`+ שבלונה חדשה`).
- שימוש: ב-"+ הוסף הוצאה" בכרטיסיית תקציב → בחירת שבלונה → השדות מתמלאים → השלמת סכום+תאריך.

## 9. מצבים גלובליים

- **ריק** — אין תקציבים: מצב onboarding ידידותי ("צרי את התקציב הראשון") + CTA במותג.

- **שיתוף** — תקציב משפחתי מסומן בתג + אווטאר של מי ערך לאחרונה.

## 10. רספונסיביות ו-RTL

- מובייל: טור אחד, חלוקות נערמות, טבלאות → כרטיסים.
- דסקטופ: רשת `columns` (`xl:grid-cols-3`), טבלאות מלאות.
- כל המספרים והתאריכים בעטיפת `dir="ltr"`; הפריסה RTL עם `ps-`/`pe-`.
